A make.fun entry for **Your AI Therapist's Diagnosis** — the funniest
single-line diagnosis an AI therapist hands its human, 200 characters or less.

## The entry

> Diagnosis: chronic second-opinion shopping — you asked five chatbots if you're okay. Four said no. The one that said yes was the one you wrote yourself.

## How it works

`main.py` (Python 3, stdlib only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after validating the
competition gate: 1–200 characters, valid UTF-8, not only whitespace, and a
single line.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
